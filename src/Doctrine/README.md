# Doctrine Component

This repository is created to make `doctrine/orm` compatible with the Hyperf framework, allowing you to use Doctrine ORM for database operations in Hyperf projects.

## Installation

Install via Composer:

```bash
composer require mineadmin/doctrine
```

## Requirements

- PHP version: \>= 8.2
- Dependency: `doctrine/orm` ~3.5

## Usage

After installation, you can use Doctrine ORM in your Hyperf project through configuration and dependency injection. For detailed usage, please refer to the [Doctrine official documentation](https://www.doctrine-project.org/projects/orm.html).
